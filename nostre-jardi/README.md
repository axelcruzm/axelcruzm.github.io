# NOSTRE JARDÍ
**Queremos crear una obra que solo existirá contigo.**
Web editorial estática de Rosela Miranda (imagen, maquillaje, vestuario, joyería) y Axel Cruz (dibujo, pintura, anatomía).

Rutas relativas, sin dependencias ni build: disponible en https://axelcruzm.github.io/nostre-jardi/ cuando GitHub Pages publique desde main.

El contacto por Instagram @axelixir es provisional; cambiar al abrir cuenta propia.

SVG conceptuales provisionales; reemplazar con pinturas y animaciones originales de Axel. No presentan dibujos de modelos reales ni una colección ficticia. Para un atlas de 48 frames, ajustar assets/animation/manifest.json y colocar canvas data-frame-animation como documentado en js/app.js.

La carpeta puede copiarse a un hosting convencional tal cual.

El kit completo con PNGs para RRSS y PDFs está en la entrega descargable separada.
